# 2026-11-19 | revise | 将 AI 绘图方法纳入产品

- 用户目标：软件负责表达、渲染、交互与结构约束；AI 根据业务资料决定图的边界、层次、表达和更新范围。用户通过图阅读与讨论，业务文件仅由 AI 编辑。
- 变化：现有[维护 Skill](../../.agents/skills/semantic-atlas/SKILL.md)接入[业务图设计指南](../../.agents/skills/semantic-atlas/references/diagram-design.md)，吸收个人 `diagramming` 中的读者问题、完整分支、业务背景、具体对象与实际显示验收方法，并补充图边界、分层判断和修改范围。现有业务所有权、共享概念、Git 审阅和校准来源契约继续沿用。
- 产品分工：软件提供可组合的表达能力，AI 决定怎样组织知识；节点数量与层数按理解成本选择。指南使用当前版本支持的字段与导航，新层级格式继续处在[方案](../proposals/2026-11-19-layered-business-viewer.md)中。

- 验证：指南独立审查通过；新上下文实际选用了新增指南，能区分示例事实与假设变化、业务所有权与阅读边界，并提出局部更新及必要上层检查。原型独立只读复核通过。既有 `maintenance-skill-contract` 与 `map-authoring` 两套检查共 8 项通过；原型 JavaScript 语法、图引用、资料链接与最终差异检查通过。
