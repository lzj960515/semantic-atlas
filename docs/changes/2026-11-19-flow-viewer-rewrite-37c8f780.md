# 2026-11-19 | revise | 统一业务流程图与 AI 工作入口

- 用户决定：总览和细图全部统一为业务流程图，允许按需求重新设计产品；原业务理解与维护两个 Skill 合并。此前精简版本的分类入口、卡片和连线没有满足阅读目标，本轮重新实现阅读主线。
- 文件与流程：继续使用 v1，不新增持久化字段。AI 显式编写总览和子流程，通过步骤的场景引用进入。归属和协作关系供调查使用，不被推断成执行顺序。没有流程资料时显示空状态。
- 阅读器：HTML 紧凑卡片、语义小图标、子流程叠层、SVG 圆角正交细线和同色小箭头。按画布比较横向与纵向可读比例，默认最多原始字号。详情默认关闭，有备注或子流程才响应；进入按钮只在详情中，返回恢复真实来路与视野。Web 目录显式只发送项目标识和名称，源码锚点保留在文件与 CLI。
- 统一 Skill：产品只内置和安装一个 `semantic-atlas`，在同一工作流完成业务调查、证据核实、流程编写和维护。必要参考资料迁入统一目录，旧维护入口退出包源；本次未修改真实用户 Skill 目录。既有观察与候选校准能力保留。
- 退出旧职责：删除关系画布、巨大菱形、手动节点位置与图片导出运行模块及相应专测，移除图像导出依赖。构建先清理生成目录，避免已删除模块残留在包中。实际阅读由浏览器验证，不为旧渲染实现保留伪 DOM。
