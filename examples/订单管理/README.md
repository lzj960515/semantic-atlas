# 订单业务示例

虚构的订单旅程，用于检查流程阅读与逐层深入，不代表任何线上系统的现行规则。

从 Semantic Atlas 仓库根目录运行：

```sh
pnpm build
node dist/cli/bin.js web --repo examples/订单管理 --port 4324 --no-open
```

默认打开“订单全流程”：顾客下单并付款，交给仓库发货；顾客提出退款申请时进入售后，
没有申请则结束订单旅程。点击下单、发货或售后节点右上角的角标，直接进入子流程。
下单流程还可以继续进入支付细图。“查看其他流程”按层级展开；“上一层”沿实际来路恢复。

所有图都是流程图；起点、判断、结果与子流程节点有不同样式。资料只由 AI 修改文件。
